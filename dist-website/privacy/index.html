プライバシーポリシー

最終更新日：2026年5月19日

SitePrinter extension（以下「当サービス」）は、ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。本ポリシーは、Google Chrome拡張機能として提供される当サービスに適用されます。

第1条（収集する情報）

当サービスは、以下の情報を収集する場合があります。

  • メールアドレス：アカウント登録時にご入力いただくメールアドレス
  • Googleアカウント情報：Google認証でログインした場合、Google OAuth 2.0を通じて提供されるメールアドレスおよびユーザーID
  • 決済情報：クレジットカード番号等の決済情報は当サービスのサーバーには保存されません。決済はStripe社のシステムを通じて行われます
  • サービス利用情報：ご契約プラン（無料 / Pro）、契約期間などのサブスクリプション情報

なお、スクリーンショットのデータおよびキャプチャされたWebページの内容はすべてお使いのブラウザ内（ローカル）で処理され、外部サーバーには一切送信されません。

第1条の2（収集しない情報）

当サービスは以下の情報を収集しません。

  • 閲覧履歴・タブの内容・URLの履歴
  • スクリーンショットおよびキャプチャしたWebページの内容（すべてローカル処理）
  • クレジットカード番号・銀行口座情報（決済はStripe社が直接処理）
  • 位置情報
  • マイク・カメラ等のセンサーデータ
  • 13歳未満の方の個人情報

第2条（情報の利用目的）

収集した情報は、以下の目的に限り利用します。

  • サービスの提供および維持管理
  • アカウントの認証・管理
  • Proプランの決済処理および契約管理
  • お問い合わせへの対応
  • 利用規約違反等の調査
  • サービスの改善および新機能の開発

第3条（第三者への情報提供）

当サービスは、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーご本人の同意がある場合
  • 法令に基づく開示が必要な場合
  • 人の生命・身体・財産の保護のために緊急に必要な場合

第3条の2（Chrome拡張機能の権限とデータアクセス）

当サービス（Chrome拡張機能）は、以下のChrome APIおよびブラウザ権限を使用します。

権限名 利用目的 アクセスするデータ
activeTab 現在開いているタブのスクリーンショット取得 ユーザーが操作中のタブのURL・スクリーンショット（ローカル処理のみ、外部送信なし）
storage（chrome.storage.local） ログイン状態・設定情報のローカル保存 認証トークン（Supabase）、拡張機能設定（外部送信なし）
tabs 印刷対象タブの制御・スクリーンショット処理 現在アクティブなタブ情報（外部送信なし）
identity GoogleアカウントによるOAuth認証 Googleログイン時のOAuthトークン
scripting Webページのキャプチャに必要なスクリプト実行 ページのDOM情報（ローカル処理のみ、外部送信なし）

取得したWebページの内容・スクリーンショットは、すべてお使いのデバイス上でのみ処理されます。これらのデータは当サービスのサーバーを含む外部の第三者に送信されることは一切ありません。

第4条（業務委託先（サブプロセッサー））

当サービスは、以下の外部サービスを利用して情報を処理します。各サービスのプライバシーポリシーも合わせてご確認ください。

サービス 利用目的 運営会社
Supabase 認証・データベース（メールアドレス、プラン情報の管理） Supabase, Inc.（米国）
Stripe 決済処理（クレジットカード情報の管理） Stripe, Inc.（米国）
Google OAuth Googleアカウントによる認証 Google LLC（米国）
Resend メール送信（登録確認・サブスクリプション通知等） Resend, Inc.（米国）
Google Tag Manager / Google Analytics ランディングページのアクセス解析 Google LLC（米国）

これらの第三者への情報提供は、サービス提供に必要な範囲に限定されます。

第4条の2（国際データ移転）

上記サブプロセッサーはいずれも米国に拠点を置く企業であり、ユーザーの個人情報（メールアドレス、プラン情報等）が日本国外（主に米国）のサーバーに保存・処理される場合があります。これらの企業はGDPRの標準契約条項（SCC）またはData Processing Agreement（DPA）に基づいてデータを適切に保護しています。詳細は各サービスのプライバシーポリシーをご参照ください。

第5条（データの保存期間）

  • アカウント情報：アカウント削除までの期間
  • 決済・サブスクリプション情報：関連する法令（電子帳簿保存法等）が定める期間
  • ローカルストレージ：拡張機能の設定情報はお使いのブラウザのローカルストレージに保存されます。アンインストールにより削除されます

第6条（Cookieおよびローカルストレージ）

当サービス（Chrome拡張機能）は、Cookieではなく Chrome の chrome.storage.local API を使用して、ログイン状態や設定情報をブラウザ内にローカル保存します。これらのデータは外部サーバーに送信されることなく、お使いのデバイス上にのみ保存されます。

第7条（ユーザーの権利）

ユーザーは、自身の個人情報について以下の権利を有します。

  • 開示請求：当サービスが保有するご自身の情報の開示を請求する権利
  • 訂正請求：誤りがある場合に訂正を請求する権利
  • 削除請求：アカウントおよびそれに紐づくデータの削除を請求する権利
  • 利用停止請求：個人情報の処理を制限するよう請求する権利

アカウントの削除は、拡張機能の設定画面（オプションページ）からご自身で行うことができます。また、下記お問い合わせ先へのご連絡によっても対応いたします。

第8条（セキュリティ）

当サービスは、ユーザーの個人情報を不正アクセス・紛失・破壊・改ざん・漏洩等から守るため、以下の技術的・組織的安全管理措置を講じます。

  • 通信の暗号化（HTTPS / TLS）
  • 認証情報はSupabaseのRow Level Security（RLS）により保護
  • 決済情報はStripeが管理し、当サービスのサーバーには保存しない
  • ローカルデータはChromeのchrome.storage.localに保存し、拡張機能外からアクセス不可

ただし、インターネット上での完全なセキュリティを保証するものではありません。

第9条（未成年者の個人情報）

当サービスは、13歳未満のユーザーの個人情報を意図的に収集しません。13歳未満の方がご利用の場合は保護者の同意が必要です。

第10条（本ポリシーの変更）

当サービスは、必要に応じて本ポリシーを変更することがあります。重要な変更については、当サービス内またはこのページにてお知らせします。変更後も当サービスをご利用の場合は、変更後のポリシーに同意したものとみなします。

本ポリシーに関するご質問・個人情報の開示・訂正・削除の請求については、以下の連絡先までお問い合わせください。
